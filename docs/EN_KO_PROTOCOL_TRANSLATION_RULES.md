# EN→KO PROTOCOL TRANSLATION RULES
**Extracted from 4,902 professional translation pairs from actual clinical protocol documents**

---

## CRITICAL TERMINOLOGY (MUST-FOLLOW RULES)

### 1. Core Protocol Terminology
**Rule**: Use standardized Korean translations for core regulatory terms consistently across all documents.

| English Term | Korean Translation | Notes |
|--------------|-------------------|-------|
| Clinical Study Protocol | 임상시험계획서 | NEVER "연구 계획서" or "프로토콜" |
| Protocol Number | 임상시험계획서 번호 | NOT "프로토콜 번호" |
| Study Title | 임상시험 제목 | NOT "연구 제목" |
| Version Number | 버전 번호 | Keep "버전" in Korean |
| Amendment | 변경계획서 | NOT "개정" for protocol amendments |
| Not applicable | 해당 없음 | Standard negation format |
| Date Issued | 발행일 | NOT "발급일" |
| Sponsor | 의뢰자 | NEVER "후원자" or "스폰서" |
| Investigator | 시험자 / 시험책임자 | Context-dependent |
| Principal Investigator | 시험책임자 | Formal title |
| Site Principal Investigator | 시험기관 시험책임자 | With institution prefix |

### 2. Study Design Terminology
**Rule**: Translate study design terms precisely using regulatory-approved Korean terminology.

| English | Korean | Context |
|---------|--------|---------|
| Multicenter | 다기관 | NOT "다중센터" |
| Open-Label | 공개 | NOT "오픈라벨" |
| Randomized | 무작위 배정 | Full phrase, not just "무작위" |
| Phase 2a | 제2a상 | Use Korean counter "상" |
| Double-blind | 이중맹검 | NOT "이중눈가림" in protocols |
| Placebo-controlled | 위약 대조 | Standard phrasing |
| Dose escalation | 용량 증량 | NOT "용량 상승" |
| Dose optimization | 용량 최적화 | Keep technical term |

### 3. Participant/Patient Terminology
**Rule**: Distinguish between "participant" (시험대상자) and "patient" (환자) based on regulatory context.

| English | Korean | Usage Context |
|---------|--------|--------------|
| Participant (in protocols) | 시험대상자 | Formal regulatory documents |
| Patient (clinical context) | 환자 | Clinical descriptions |
| Subject | 시험대상자 | Same as participant |
| Informed consent | 시험대상자 동의서 | NOT "동의서" alone |
| Inclusion criteria | 포함 기준 | NOT "선정 기준" |
| Exclusion criteria | 제외 기준 | Standard regulatory term |
| Eligibility criteria | 적격성 기준 | For randomization context |
| Enrollment | 등록 | NOT "입학" or "참여" |
| Withdrawal | 참여 중단 | Or "탈락" for screening failures |
| Discontinuation | 중도 탈락 | For early termination |

### 4. Safety and Efficacy Terminology
**Rule**: Use ICH-GCP aligned Korean safety terminology precisely.

| English | Korean | Critical Notes |
|---------|--------|---------------|
| Adverse Event (AE) | 이상사례 | NEVER "부작용" (side effect) |
| Serious Adverse Event (SAE) | 중대한 이상사례 | Include "중대한" prefix |
| Treatment-Emergent AE (TEAE) | 투여 중 발생한 이상사례 | Full descriptive phrase |
| Adverse Drug Reaction (ADR) | 약물이상반응 | Different from AE |
| Safety | 안전성 | NOT "안전" alone |
| Efficacy | 유효성 | NOT "효과" (effect) |
| Tolerability | 내약성 | Technical term |
| Primary Endpoint | 일차 평가변수 | NOT "1차 종료점" |
| Secondary Endpoint | 이차 평가변수 | Follow numbering pattern |
| Exploratory Endpoint | 탐색적 평가변수 | Descriptive term |

### 5. Regulatory Compliance Terminology
**Rule**: Use exact Korean translations for GCP/ICH regulatory terms to ensure compliance.

| English | Korean | Regulatory Context |
|---------|--------|--------------------|
| Good Clinical Practice (GCP) | 임상시험관리기준(GCP) | Keep English acronym |
| International Council for Harmonization (ICH) | 의약품 허가를 위한 국제조화회의(ICH) | Full formal name |
| Declaration of Helsinki | 헬싱키 선언 | Proper name |
| Ethics Committee | 윤리위원회 | Generic term |
| Institutional Review Board (IRB) | 기관생명윤리위원회(IRB) | Korean term + acronym |
| Independent Ethics Committee (IEC) | 독립윤리위원회(IEC) | With "독립" prefix |
| Confidential | 비밀 유지 | For headers/footers |
| Confidentiality Statement | 비밀 유지 서약 | Section heading |
| Privileged or confidential | 특권적 또는 기밀 | Legal phrasing |

## MODAL VERB TRANSLATION PATTERNS (MUST-FOLLOW)

### 6. "Will" → Future Actions in Protocols
**Rule**: Translate "will" based on whether it's procedural (no modal needed) or future intention.

**Pattern 1: Procedural actions** (remove "will", use direct Korean verb)
```
EN: Interested participants will sign the ICF.
KO: 희망 시험대상자는 적절한 시험대상자 동의서에 서명해야 한다.
     [직접 조사 + 해야 한다]

EN: The Investigator will review symptoms prior to procedures.
KO: 시험자는 일체의 침습적 절차를 실시하기 전에 증상을 검토한다.
     [현재형 + 한다]
```

**Pattern 2: Future consequences** (keep future tense)
```
EN: These restrictions will apply equally to all future information.
KO: 이러한 공개 제한은 모든 향후 정보에 동일하게 적용된다.
     [현재형 but implies future]
```

### 7. "Must" → Strong Obligation
**Rule**: Always translate "must" as "~해야 한다" (mandatory) or "~하여야 한다" (formal regulatory).

```
EN: Persons to whom information is disclosed must be informed...
KO: 정보가 공개되는 사람에게 반드시 고지하여야 한다.
     [반드시 + 고지하여야 한다 = strongest obligation]

EN: Study documentation must indicate if a visit was conducted...
KO: 임상시험 문서에는 방문 수행 여부가 명시되어야 한다.
     [명시되어야 한다 = must be documented]

EN: The Principal Investigator must ensure that all procedures...
KO: 시험책임자는 모든 절차가 철저히 준수하여 수행되도록 해야 한다.
     [해야 한다 = must ensure]
```

### 8. "Shall" → Regulatory Requirement (Softer than "must")
**Rule**: Translate "shall" as "~할 수 있다" (can/may) or "~해야 한다" based on context. In protocols, "shall" often = procedure guidance.

```
EN: The participant shall be asked a nonleading question...
KO: 시험대상자에게 다음과 같은 비유도적 질문을 할 수 있다.
     [할 수 있다 = procedural guidance, not strict requirement]

EN: The Investigator shall obtain informed consent...
KO: 시험자는 시험대상자 동의서를 받아야 한다.
     [받아야 한다 = regulatory requirement]

EN: The Investigator shall follow-up newborn infants...
KO: 시험자는 신생아를 최소 12개월 동안 추적 관찰해야 한다.
     [해야 한다 = mandatory follow-up]
```

### 9. "Should" → Recommendation (Not Strict)
**Rule**: Translate "should" as "~해야 한다" (recommendation) with context showing it's advisory.

```
EN: Oxygen saturation should be measured while on oxygen.
KO: 산소포화도는 표준 가정용 보조 산소 투여 중에 측정해야 한다.
     [측정해야 한다 = should measure, but advisory]

EN: It should be noted that liver weight increases are common...
KO: 간 중량 증가는 흔히 나타나며... 유의해야 한다.
     [유의해야 한다 = should note, advisory]
```

### 10. "May" → Permission or Possibility
**Rule**: Translate "may" as "~할 수 있다" (can/may) or "~될 수 있다" (passive possibility).

```
EN: Information may not be disclosed unless required...
KO: 공개가 요구되지 않는 한 공개될 수 없다.
     [될 수 없다 = may not / cannot be disclosed]

EN: Visits may be conducted through telehealth platforms.
KO: 임상시험 방문은 원격의료 플랫폼을 통해 수행될 수 있다.
     [수행될 수 있다 = may be conducted]

EN: Medications may be affected by ritonavir.
KO: 리토나비르에 의해 영향을 받을 수 있는 병용 약물
     [받을 수 있는 = may be affected]
```

### 11. "Can" → Ability or Possibility
**Rule**: Translate "can" as "~할 수 있다" emphasizing capability.

```
EN: Who can provide informed consent.
KO: 동의를 제공할 수 있는 의지와 능력이 있는 경우.
     [제공할 수 있는 = able to provide]

EN: The event can be readily explained by other factors.
KO: 사례는 다른 요인으로 쉽게 설명될 수 있다.
     [설명될 수 있다 = can be explained]
```

## PASSIVE VOICE PATTERNS (SHOULD-FOLLOW)

### 12. Passive Voice → Korean Active or Passive Depending on Agent
**Rule**: English passive often becomes Korean active with implied agent, OR Korean passive with ~되다.

**Pattern 1: Passive → Active (agent implied)**
```
EN: If the participant is eligible, invasive procedures will be performed.
KO: 시험대상자가 자격을 갖춘 경우, 침습적 절차를 수행한다.
     [수행한다 = active voice, agent (investigator) implied]

EN: Participants will be assessed for eligibility.
KO: 시험대상자에 대해 적격성을 평가한다.
     [평가한다 = active, evaluator implied]
```

**Pattern 2: Passive → Korean Passive (~되다)**
```
EN: Study documentation must indicate if a visit was conducted...
KO: 임상시험 문서에는 방문이 수행되었는지가 명시되어야 한다.
     [수행되었는지 = passive ~되다 form]

EN: All remote visits must be conducted in compliance with GCP.
KO: 모든 원격 방문이 GCP를 준수하여 수행되도록...
     [수행되도록 = passive causative]
```

**Pattern 3: "To be performed" → Active/Passive Mix**
```
EN: To be performed after the participant is eligible.
KO: 시험대상자가 적격으로 판단된 후 수행된다.
     [판단된 = passive, 수행된다 = passive]

EN: Body height will be obtained and recorded only at screening.
KO: 신장은 스크리닝 시에만 측정하여 기록한다.
     [측정하여 기록한다 = active voice, agent implied]
```

## STRUCTURAL PATTERNS (SHOULD-FOLLOW)

### 13. Long Compound Sentences → Break into Korean Clauses
**Rule**: English compound sentences with multiple clauses should be broken using Korean conjunctions or restructured.

```
EN: Participants who meet the selection criteria will be assessed for eligibility for randomization.
KO: 선정 기준에 부합하는 시험대상자에 대해 무작위 배정에 대한 적격성을 평가한다.
     [Structure: [관형사형 clause] + 에 대해 + [main verb]]

EN: Participants eligible for randomization will be randomized in a 1:1 ratio to receive Treatment A or Treatment B.
KO: 무작위 배정에 적합한 시험대상자는 Treatment A 또는 Treatment B를 1:1 비율로 무작위 배정받는다.
     [Structure: [관형사형 clause] + 는 + [object] + 을/를 + [verb]]
```

### 14. Title Case / Section Headings → Korean Sentence Case
**Rule**: English title case becomes Korean sentence case with no special capitalization.

```
EN: PRINCIPAL INVESTIGATOR SIGNATURE PAGE
KO: 시험책임자 서명 페이지
     [No ALL CAPS in Korean]

EN: Study Design:
KO: 임상시험 설계:
     [Colon maintained]

EN: Primary Endpoints
KO: 일차 평가변수
     [No capitalization difference]
```

### 15. "By my signature" Formal Statements → Korean Formal Register
**Rule**: Use formal polite endings (합니다/습니다) for signature statements, not standard declarative.

```
EN: By my signature, I confirm that I have reviewed this protocol and find its content acceptable.
KO: 본인은 서명을 통해, 본 임상시험계획서를 검토하고 그 내용이 허용 가능함을 확인하였습니다.
     [확인하였습니다 = formal past tense polite]

EN: I agree to personally supervise the conduct of this study...
KO: 본 임상시험의 수행을 직접 감시할 것에 동의합니다.
     [동의합니다 = formal present polite]
```

## AVOID PATTERNS (Common Mistakes)

### 16. AVOID: Over-Literal Translation of Articles/Determiners
**Wrong Example:**
```
❌ EN: The investigator will review the symptoms.
❌ KO: 그 시험자는 그 증상들을 검토할 것이다.
     [Unnatural: Korean doesn't need articles]

✅ CORRECT:
✅ KO: 시험자는 증상을 검토한다.
     [Natural: no articles, direct verb]
```

### 17. AVOID: Translating "Study" as "연구" in Regulatory Contexts
**Wrong Example:**
```
❌ EN: Clinical Study Protocol
❌ KO: 임상 연구 계획서
     [Wrong: "연구" is academic research, not regulatory trial]

✅ CORRECT:
✅ KO: 임상시험계획서
     ["시험" = regulatory clinical trial]
```

### 18. AVOID: Using "부작용" for "Adverse Event"
**Wrong Example:**
```
❌ EN: Adverse events will be monitored.
❌ KO: 부작용을 모니터링한다.
     [Wrong: "부작용" = side effect, not AE]

✅ CORRECT:
✅ KO: 이상사례를 모니터링한다.
     ["이상사례" = regulatory term for AE]
```

### 19. AVOID: Omitting Korean Formal Markers in Regulatory Text
**Wrong Example:**
```
❌ EN: Participants not eligible for randomization will be included in Arm 3.
❌ KO: 무작위 배정에 적격하지 않은 시험대상자 시험군 3에 포함되어 83-0060 투여받는다.
     [Missing: 는 subject marker, 을 object marker]

✅ CORRECT:
✅ KO: 무작위 배정에 적격하지 않은 시험대상자는 시험군 3에 포함되어 83-0060을 투여받는다.
     [Include: 는, 을 particles for formal register]
```

### 20. AVOID: Mixing Formal and Informal Verb Endings
**Wrong Example:**
```
❌ KO: 시험대상자는 동의서에 서명해. [informal 해]

✅ CORRECT:
✅ KO: 시험대상자는 동의서에 서명해야 한다. [formal 한다]
     OR: 시험대상자는 동의서에 서명한다. [declarative formal]
```

### 21. AVOID: Direct Translation of Passive "by" → Korean "에 의해"
**Wrong Example:**
```
❌ EN: Procedures may be performed by trial personnel.
❌ KO: 절차는 임상시험 직원에 의해 수행될 수 있다.
     [Too literal: 에 의해 sounds unnatural]

✅ CORRECT:
✅ KO: 임상시험 직원이 절차를 수행할 수 있다.
     [Active voice with 이/가 subject marker]
     OR: 절차는 임상시험 직원이 수행할 수 있다.
     [Topic-comment structure]
```

### 22. AVOID: Translating Every "and" as "그리고" or "및"
**Wrong Example:**
```
❌ EN: Safety and efficacy
❌ KO: 안전성 그리고 유효성
     [Unnatural: 그리고 is for sentences]

✅ CORRECT:
✅ KO: 안전성 및 유효성
     ["및" for noun conjunction]
     OR: 안전성과 유효성
     ["과/와" also acceptable]
```

## STYLE PREFERENCES

### 23. Formal Register for Protocols
**Style**: Use formal declarative endings (~한다, ~된다) throughout protocol body text, NOT polite (~합니다) except in consent forms and signature pages.

```
PROTOCOL BODY TEXT:
✅ 시험대상자는 적격성 기준을 충족해야 한다. [한다 form]
✅ 무작위 배정은 1:1 비율로 수행된다. [된다 form]

CONSENT FORMS / SIGNATURE PAGES:
✅ 본인은 동의합니다. [합니다 form]
✅ 시험에 참여하겠습니다. [겠습니다 form]
```

### 24. Bilingual Presentation for Technical Terms
**Style**: Present technical/regulatory terms as Korean(English, ABBREV) on first mention.

```
✅ 임상시험관리기준(Good Clinical Practice, GCP)
✅ 기관생명윤리위원회(Institutional Review Board, IRB)
✅ 이상사례 공통 용어 기준(Common Terminology Criteria for Adverse Events, CTCAE)
```

### 25. Date Format Localization
**Style**: Adapt date formats to Korean conventions.

```
EN: 18 July 2025
KO: 2025년 7월 18일 [YYYY년 M월 D일]

EN: Day 1
KO: 1일차 [N일차 for study days]

EN: Days 2-7
KO: 제2일~제7일 [제N일 for formal protocol schedule]
```

### 26. Number and Unit Formatting
**Style**: Maintain English format for numbers/units but use Korean counters where appropriate.

```
✅ 60명의 시험대상자 [명 counter for people]
✅ 1:1 비율 [ratio kept as 1:1]
✅ ≥60세 [age kept as ≥60]
✅ BMI >25 kg/m² [units unchanged]
✅ 제1상, 제2a상 [phase uses 제N상 format]
```

### 27. Abbreviation Handling
**Style**: Keep English abbreviations for medical/technical terms, provide Korean on first use.

```
✅ COVID-19 [no translation needed]
✅ PK (약동학, Pharmacokinetics) [Korean + English + abbrev]
✅ PD (약력학, Pharmacodynamics)
✅ AE (이상사례, Adverse Event)
✅ SAE (중대한 이상사례, Serious Adverse Event)
✅ TEAE (투여 중 발생한 이상사례, Treatment-Emergent Adverse Event)
```

## CONCRETE EXAMPLES FROM ACTUAL PROTOCOL TRANSLATIONS

### Example 1: Protocol Title Section
```
EN: A Multicenter, Open-Label, Randomized Phase 2a study to evaluate Safety and Efficacy
    of 83-0060 and Standard of Care in Non-hospitalized Symptomatic Adult Participants
    with Mild to Moderate COVID-19

KO: 경증 내지 중등증의 COVID-19가 있는 비입원 유증상 성인 시험대상자를 대상으로
    83-0060 및 표준 치료의 안전성 및 유효성을 평가하기 위한
    다기관, 공개, 무작위 배정 제2a상 시험
```

**Key Patterns:**
- "Multicenter, Open-Label, Randomized Phase 2a study" → "다기관, 공개, 무작위 배정 제2a상 시험"
- "to evaluate" → "평가하기 위한" (purpose clause with ~하기 위한)
- "Participants" → "시험대상자" (regulatory term)
- "Mild to Moderate" → "경증 내지 중등증" (using 내지 for range)

### Example 2: Confidentiality Statement
```
EN: The information in this document contains trade secrets and commercial information
    that are privileged or confidential and may not be disclosed unless such disclosure
    is required by applicable laws and regulations.

KO: 본 문서에 포함된 정보에는 특권적 성격의 영업기밀 및 상업적 정보가 포함되어 있으며,
    해당 법률 및 규정에 따라 공개가 요구되지 않는 한 공개될 수 없다.
```

**Key Patterns:**
- "may not be disclosed" → "공개될 수 없다" (strong prohibition)
- "unless such disclosure is required" → "공개가 요구되지 않는 한" (conditional with 않는 한)
- Formal legal register maintained throughout

### Example 3: Eligibility Criteria
```
EN: Participant is eligible for randomization if he/she meets all inclusion criteria
    and none of exclusion criteria and has at least 1 characteristic or underlying
    medical condition associated with increased risk of developing severe outcomes
    from COVID-19.

KO: 시험대상자는 모든 포함 기준을 충족하고 어떠한 제외 기준도 충족하지 않으며
    COVID-19로 인해 중증 결과가 발생할 위험이 증가하는 특성이나 의학적 기저 질환이
    1개 이상 있는 경우 무작위 배정에 적합하다.
```

**Key Patterns:**
- "if he/she meets" → "충족하고...경우" (conditional restructured to end)
- "is eligible for" → "적합하다" at sentence end
- "at least 1" → "1개 이상"
- Multiple conditions connected with "고" (and) and "며" (and also)

### Example 4: Passive Voice Procedures
```
EN: Following the screening period, participants who meet the selection criteria
    will be assessed for the eligibility for randomization.

KO: 스크리닝 기간 이후, 선정 기준에 부합하는 시험대상자에 대해
    무작위 배정에 대한 적격성을 평가한다.
```

**Key Patterns:**
- "will be assessed" → "평가한다" (active voice, agent implied)
- "participants who meet" → "부합하는 시험대상자" (relative clause as modifier)
- "for the eligibility for randomization" → "무작위 배정에 대한 적격성을" (nested possession)

### Example 5: Modal Verb "Must"
```
EN: The Principal Investigator must ensure that all remote visits and procedures
    are conducted in full compliance with Good Clinical Practice (GCP) guidelines
    and study protocol requirements.

KO: 시험책임자는 모든 원격 방문과 절차가 GCP 지침 및 본 임상시험계획서 요건을
    철저히 준수하여 수행되도록 해야 한다.
```

**Key Patterns:**
- "must ensure that" → "~되도록 해야 한다" (causative + obligation)
- "are conducted in compliance" → "준수하여 수행되도록" (passive + compliance)
- "Good Clinical Practice (GCP)" → "GCP" (abbrev kept, full name earlier)

## SUMMARY OF KEY RULES FOR LLM PROMPT

**When translating English clinical protocols to Korean:**

1. **Use standardized regulatory terminology** for all protocol-specific terms (임상시험계획서, 시험대상자, 이상사례, etc.)
2. **Translate modal verbs contextually**: "will" often disappears, "must" = ~해야 한다, "shall" = ~할 수 있다 or ~해야 한다, "may" = ~할 수 있다
3. **Convert passive voice to active** when agent is implied (procedures "are performed" → "수행한다")
4. **Use formal declarative register** (~한다, ~된다) in body text, NOT polite (~합니다) except signatures/consent
5. **Maintain bilingual presentation** for technical terms on first mention: Korean(English, ABBREV)
6. **Restructure long sentences** using Korean clause connectors (고, 며, 으며, 경우)
7. **Avoid over-literal translation** of articles, "by" (에 의해), every "and" (그리고)
8. **Use Korean counters** for people (명), phases (제N상), days (일차, 제N일)
9. **Keep technical abbreviations** in English (COVID-19, PK, PD, BMI, GCP, ICH, IRB)
10. **End eligibility statements** with condition: "모든 기준을 충족하는 경우 적합하다"
